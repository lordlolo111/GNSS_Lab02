*Ziel*: 
	Ziel dieser Aufgabe ist es unterschiedliche Satellitenkonstellationen  über  einen  bestimmten  Zeitraum  zu  analysieren  und  zu  visualisieren. 
    Zusätzlich soll der „Dilution of precision“ (DOP) – Wert berechnet werden, welcher den Einfluss der geometrischen Verteilung  von  Satelliten  im  Raum  beschreibt  und  angibt,  wie  akkurat  eine  GNSS-Positionsbestimmung werden kann.

*Daten*:
	Die folgendenen Daten wurden zur Verfügung gestellt:
    ecef.pos - Satellitenpositionen in ECEF-Koordinaten
    ecsf.pos - Satellitenpositionen in ECSF-Koordinaten
